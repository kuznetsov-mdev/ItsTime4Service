# 1.1.0 (3) — release candidate

## Изменения для RuStore

- Добавлены резервные копии и восстановление данных, перенос между Android и iOS.
- Теперь можно поделиться регламентом автомобиля и выбрать передаваемые работы и личные сведения.
- Добавлены защита файла паролем, предпросмотр и выбор действий при совпадении данных.
- Комментарии к обслуживанию стали многострочными.
- Во всех полях даты открывается календарь.
- При сохранении форма прокручивается к первому незаполненному обязательному полю.
- В списке автомобилей отображается актуальное количество ближайших и всех работ.

## Состояние ревизии от 23.11.2026

Android и iOS используют версию 1.1.0 и номер сборки 3. Для `db1567d` основная сессия зафиксировала 727 успешных Android host-тестов и 709 iOS Simulator-тестов без ошибок и пропусков. Собраны Debug и `upgradeCheck` APK. На чистом пакете Android-эмулятора обновление 1.0.0 → 1.1.0 сохранило исходные колонки и перевело схему БД с 5 на 7. [Прогон 23.11.2026](../research/transfer-ui-release-verification.md#evidence-2026-11-23).

Независимый прогон подтвердил 727 Android host и 709 тестов на iOS Simulator 18.3.1 без ошибок и пропусков. На Android API 35 прошли проверка шифрования и все шесть системных сценариев, включая передачу защищённого файла с проверкой SHA-256. На iOS 27 прошли шесть из семи системных сценариев. Итог независимой приёмки — **BLOCKED**. В обоих прогонах передача в «Файлы» остановилась на папке стенда до подтверждения и проверки SHA-256. [Независимая приёмка](../research/transfer-ui-release-verification.md#independent-qa-2026-11-23).

## Запуск на Android API 24

24.11.2026 на эмуляторе Android 7.0 воспроизведён сбой холодного запуска с `NoClassDefFoundError` для `java.time.LocalTime` при чтении настроек. Android-приложение теперь включает `coreLibraryDesugaring`. После установки свежего Debug APK поверх прежнего пакета открылись главный экран и настройки со временем напоминания. Изолированный минифицированный APK на том же эмуляторе прошёл шифрование и расшифровку тестовой копии. Замеры на физическом устройстве API 24 остаются открытыми.

## Перед публикацией

Открыты повторное независимое ревью `db1567d` и подтверждённая передача в «Файлы» на iOS 27. На физическом Android API 24 требуется проверка времени PBKDF2, памяти и отзывчивости отмены. Точная минимальная iOS 18.2, физическое iOS-устройство и свежий ручной обмен между установленными Android- и iOS-приложениями остаются непроверенными. Выпуск ожидает закрытия обязательных проверок, проверки актуального подписанного артефакта и явной пользовательской приёмки.

Результаты и трассировка критериев собраны в [отчёте о проверке переноса](../research/transfer-ui-release-verification.md).
