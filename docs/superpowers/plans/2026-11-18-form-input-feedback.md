# Form input feedback implementation plan

**Goal:** Комментарий принимает переносы строк; нажатие на дату открывает календарь без цифровой клавиатуры.

**Spec:** `specs/presentation.md`. Поведение прямо поручено пользователем по отзыву RuStore 18.11.2026. Работа выполняется самостоятельно в текущей ветке, с разрешёнными пользователем логическими коммитами, без push. Изменения экспорта/импорта сохраняются отдельно.

**Architecture:** Значения и сохранение остаются у существующих форм/ViewModel. Общий `AppDateField` владеет только открытием календаря и временным выбором Material3; `LabeledDateField` добавляет компактную подпись. В callback передаются прежние локализованные восемь цифр. Момент календаря трактуется как UTC-дата, без системного часового пояса. `LabeledMiniField` оставляет IME Done только однострочным полям.

**Files:** `docs/index.html`, `specs/presentation.md`, `specs/test-plan.md`, `dev_plan.md`; `ui/components/fields/{DateFields,LabeledMiniField}.kt`, `ui/icons/ItsTime4ServiceIcons.kt`, три `composeResources/values*/strings.xml`; даты в `CarFormTaskBlock`, `TaskFormScreen`, `HistoryEntryDialog`, `NewHistoryEntryDialog`, `HistoryFilterDialog`; UI-тесты общих полей и wiring форм.

**Review focus:** Enter не вызывает сохранение; отмена не пишет промежуточный выбор; UTC не сдвигает дату; вторая граница фильтра не остаётся без названия; календарь доступен на маленьком экране и в обеих темах. UI/Material3 guidance используется напрямую: поисковая база `ui-ux-pro-max` не дала подходящего результата для этой задачи.

- [x] При невалидном сохранении увеличивать счётчик попыток; Compose прокручивает первое обязательное поле. В форме машины приоритет у марки/пробега, затем первого невалидного блока; повторные сохранения тоже прокручивают. Проверить порядок и реальную видимость поля на маленьком экране.
