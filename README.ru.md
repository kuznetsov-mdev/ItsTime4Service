# Пора на ТО

**Учёт регламентного ТО по пробегу и по времени — что наступит раньше.**

«Пора на ТО» — приложение на Kotlin Multiplatform (Android + iOS, общий UI на Compose Multiplatform) для контроля регламентных работ по автомобилю. Каждая работа — замена масла, тормозные колодки, ремень ГРМ — отслеживается и по интервалу в километрах, и (опционально) по интервалу во времени; статус подсвечивается по тому сроку, что наступает раньше: спокойный тил, пока запас большой, янтарь — в окне напоминания, красный — после просрочки.

## Возможности

- **Гараж на несколько авто** — список всех машин с кольцом-гейджем, по которому сразу видно, сколько работ скоро наступит или просрочено.
- **Напоминание по двум осям** — каждая работа может иметь интервал в км и, опционально, интервал в месяцах; статус определяется тем сроком, что наступает раньше — это важно для масла и жидкостей, которые "стареют" по календарю даже при простое машины.
- **Трёхуровневый цветовой статус** — В порядке / Скоро / Просрочено, единый цветовой язык на всех экранах и в обеих темах.
- **История обслуживания** — каждая выполненная работа фиксируется с датой, пробегом, ценой и названием СТО, чтобы всегда можно было посмотреть, что и когда делалось.
- **Отметка «выполнено» в один тап** — прямо из списка работ, без захода в форму; прогресс и статус пересчитываются мгновенно.
- **Быстрое редактирование пробега** — обновление текущего пробега прямо на экране авто, без полной формы редактирования.
- **Пресеты регламентных работ** — при добавлении авто можно сразу подставить типовые работы (масло, колодки, воздушный фильтр, ремень ГРМ) вместо ввода всех интервалов вручную.
- **Локальные push-уведомления** — напоминание, когда работа входит в окно напоминания или становится просроченной, с анти-спам правилом, чтобы одна и та же работа не напоминала о себе слишком часто.
- **Светлая / тёмная / системная тема** и переключение единиц **км / мили**.

## Технологический стек

Kotlin Multiplatform · Compose Multiplatform (общий UI) · SQLDelight (локальная БД) · Koin (DI) — Android и iOS из единой кодовой базы.
